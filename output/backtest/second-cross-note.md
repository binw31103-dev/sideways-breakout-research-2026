# 「金叉 → 下水 → 二次金叉」形态研究（2026-11-07）

> 起因：用户观察到牧原股份（002714）在 0 轴附近第一次金叉后下水、震荡几天，再出现水上金叉就上涨了，
> 希望找出同类的其他票。
>
> **结论先说：这个形态本身（首次金叉贴近 0 轴）在历史上是所有金叉里最差的一类；
> 真正成立的是它的镜像 —— 首次金叉在深水，二次金叉仍在水下。**
>
> 数据：`output/cache/kline_long`（比例复权，统一按「股」计成交量），2023-07 起，剔除 2024-09，
> 20日均额 ≥ 5000 万，中证1000 为基准，次日开盘入场。
> 脚本：`scripts/research/zero_axis_second_cross.py`、`second_cross_variants.py`、`second_cross_live.py`。

用户的描述是准确的：先在 0 轴附近金叉 → 下水 → 震荡 → 二次金叉 → 上涨。
下面检验这个形态在历史上是不是有统计意义上的优势。

## 二、形态定义

```
第一次金叉 j   DIF 上穿 DEA，且 |DIF|/收盘 ≤ near（默认 1%）
回踩           j 与 k 之间出现过死叉，且 DIF 曾 < 0
第二次金叉 k   DIF 再次上穿 DEA，DIF > 0
间隔           2 ≤ k − j ≤ 20 个交易日
```

全部只用信号日及之前的数据，无未来函数。共 31 059 个二次金叉样本。

指标用**同日相对超额**：该金叉的超额先减掉当天全部金叉的平均超额，
这样才能回答"选这一只而不是当天其他金叉，值多少"。单位百分点。

## 五、必须提醒的三件事

### 1. 首次金叉"贴近 0 轴"是减分项，不是加分项

0 轴附近意味着 MA12 ≈ MA26，也就是**没有趋势**。在这里金叉 → 死叉 → 再金叉，
本质是横盘中的随机穿越，没有任何一方真正占优。牧原 11 月这一波走对了，
但它与"首次金叉在深水"的样本相比，统计学上处于劣势一侧（-0.36 vs +0.79）。

### 2. 数据坑：最新缓存的成交量单位不统一

`output/cache/kline/2026-11-06/` 里 **3832 个腾讯来源的文件按「手」，1141 个新浪回退的文件按「股」，
相差 100 倍**。用重叠日与 `kline_long` 逐一核对过（抽查 59 个文件全部吻合）。

不归一的话，成交额过滤会把所有腾讯来源的大票杀掉：宁德时代（300750）算出来只有 1.3 亿，
真实约 200 亿。我第一次跑出的名单只有 178 个，修正后是 1043 个 —— **过滤误杀了大半市场**。

`second_cross_live.py` 已加 `normalise_volume()` 按 source 字段归一。
**建议在 `run_daily_screen_and_notify.py` 或缓存写入处也补上这个归一**，否则任何读这个目录的
统计（换手、成交额、量比）都会错。

### 3. 形态容量很大，必须限只数

S 组平均每天 3 个、最多一天 210 个。加 RSI ≤ 45 和距低点 ≤ 8% 后仍是中位 3 个。
不做排序截取就等于没筛。

## 七、局限

- 只含当前在市股票，退市股缺失，真实效果低于回测。
- 剔除 2024-09，但仍有 2024-02、2026-07 两段单边行情主导。
- 未扣交易成本。
- t 值不显著，本文所有结论只能当"方向参考"，不能当"规则依据"。
- 新段（2026-07 起）样本短、beta 高。
- 形态定义里的 near / gap / 深度阈值都是看着分档结果定的，存在挑选偏差。
