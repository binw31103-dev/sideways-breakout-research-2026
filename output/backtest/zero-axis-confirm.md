> **范围**：只研究「零轴金叉」这一个信号。不涉及 v1.3、v2.6、v2.7 等其他策略，
> 也不评判其他规则里的 RSI 条件。
>
> **问题**：零轴金叉已经出现了，看 MA / RSI 能不能帮你判断这次金叉靠不靠谱？
>
> 脚本：`scripts/research/zero_axis_confirm.py`

## 一、方法：基准必须是「同类金叉」

上一轮我做错了——把 MA/RSI 拿去和全市场比，那是在问"这个指标能不能选股"。
这一轮问的是不同的问题：**在已经金叉的股票里，能不能再分出好坏。**

所以基准改成：**同一天、同一类金叉的平均超额**（`类内相对`）。
正数 = 这个条件帮你挑到了更好的金叉；负数 = 帮倒忙。

金叉分类沿用 `zero-axis-cross.md`：

| 代号 | 定义 | 样本 |
| --- | --- | --- |
| C | 水上且 0 轴附近（AA 且 \|DIF\|/价 ≤1%） | 2 753 |
| CU | 水下且 0 轴附近（UU 且 \|DIF\|/价 ≤1%） | 3 466 |
| AA | 纯水上 | 5 400 |
| UU | 纯水下 | 10 170 |
| XC | 跨轴（DIF>0, DEA<0） | 435 |

持有 20 日，超额相对中证1000。

## 三、结论二：RSI 基本上没用，它是 MA 距离的另一种写法

### RSI 各档没有单调关系

| 日 RSI | C 类内相对 | CU 类内相对 |
| --- | --- | --- |
| 45~50 | — | −0.376 |
| 50~55 | +0.475 | +0.027 |
| 55~60 | −0.257 | +0.531 |
| 60~65 | +0.299 | −0.847 |
| 65~70 | −1.037 | — |

符号在相邻档之间来回翻转（＋ − ＋ −），没有任何趋势。这不是"效果小"，这是**噪声的形状**。

### 原因：RSI 和 MA 距离几乎是同一个变量

| 类别 | 距 MA30 与 日 RSI 的相关系数 |
| --- | --- |
| C | **+0.65** |
| CU | **+0.80** |

在 CU 这一类里，RSI 有 64%（0.8²）的变异能被"离 MA30 多远"解释。
所以**用 RSI 做确认，等于用 MA 距离做确认，但精度更低**。

唯一看起来有效的是「日 RSI ≥ 60 → 类内相对 −1.06（CU）」，但样本只有 262，
且三段是 −1.49 / −0.71 / n/a，中间段幅度很小。**不建议采纳。**

## 四、可执行的确认方案

### 4.1 对 0 轴附近水上金叉（C）

```
✅ 确认成立：距 MA30 在 0~5%，且距 60 日低点 < 25%
   20 日类内相对 +0.37（t+1.3），三段 +0.43 / +0.30 / +0.86
   （只要求 MA30 0~2% 时是 +0.85，但样本只剩 701）

❌ 应当减分：距 MA30 ≥ 5%，或距 60 日低点 ≥ 25%
   这两条各自单独都是三段全负（−0.61 / −0.94）
```

### 4.2 对 0 轴附近水下金叉（CU）

```
✅ 确认成立：距 MA30 在 0~5%，且距 60 日低点 < 25%
   20 日类内相对 +0.61（t+1.9），三段 +0.75 / +0.46 / +1.07 —— 本轮最稳的一格

❌ 应当减分：距 MA30 ≥ 5%（−1.10），或距 60 日低点 ≥ 25%（−1.17）
```

### 4.3 具体参数（写死，不再调）

| 参数 | 取值 | 依据 |
| --- | --- | --- |
| 距 MA30 上限 | < 5% | ≥5% 三段全负 |
| 距 MA30 下限 | > 0% | <0 时 C 为 −1.93、CU 为 −0.51 |

## 五、必须说明的局限

1. **t 值最高只有 +2.2**，且持仓 20 日、相邻样本重叠，真实显著性低于表面数字。
   这是"方向可信、幅度打折"的结论。
2. **类内相对的基准是同类金叉均值**，所以 +0.61 的意思是"比同一天其他水下金叉好 0.61 个百分点"，
   不是"能赚 0.61%"。
3. **样本剔除 2024-09**，只含在市股票。
4. **0~5% 这个带宽是我看数据后定的**，存在挑选偏差。切细显示最优在 1~3%，
   说明带宽边界不精确，但"5% 以上变差"这个方向是稳的（三个持有期、三段都一致）。
5. **没有多因子正交**，没有控制市值、波动率、行业。
6. **RSI 的否定结论较弱**：只能说"在零轴金叉这个子集里没有增量"，不能推广到其他场景。
