# 通达信横盘启动公式说明

## 一、现有公式

只保留一个辅助指标，供手动看图时叠加周线 RSI / MACD：

- `01_HPBASE_周线辅助指标.txt`：技术指标公式，输出 `RSI14#WEEK`、`MACD` 的周线跨周期值。

安装：公式管理器 → 技术指标公式 → 新建 `HPBASE` → 粘贴内容。

## 二、为什么没有条件选股公式

v2.3.1 / v2.4 / v2.5 时代的三份条件选股公式（`HPRED231`、`HPRED24`、`HPEDGE25`）对应的是已被 v2.6 统一模型和 v1.3 右侧启动取代的旧口径，2026-11-07 清理时一并移除。

当前选股全部由 Python 脚本完成，规则以 `当前筛选逻辑-v2.7.txt` 和代码为准：

```bash
python3 scripts/run_daily_screen_and_notify.py    # 收盘选股（三条清单）
```

通达信现在只用于人工复核时看图。如果确实需要盘中在通达信里粗筛，请以 Python 脚本的输出为准，不要另建口径不一致的公式。

## 三、周线辅助指标用法

把 `HPBASE` 叠加到副图后，可直接看到周线 RSI 和周线 MACD 的位置，用于判断：

- 周 RSI 是否仍在低位（v2.6 核心区间 24–42，v1.3 为 32–48）。
- 周 MACD 是否仍在零轴下方，以及是否继续恶化。

指标只做辅助确认，不单独作为纳入观察池的理由。

## 四、数据口径注意事项

- 跨周期引用依赖完整周线数据；周线未更新时结果会滞后。
- 通达信复权方式与项目 Python 数据源（腾讯前复权 / 新浪不复权 + 复权因子）存在差异，数值不必完全对齐。
- 人工复核结论仍使用通过、观察、剔除，不计算评分。
